# 地图信息面板 (Map Info Mod)

杀戮尖塔2 (Slay the Spire 2) v0.107.0 的 DLL 模组，在地图界面叠加信息面板。

## 功能

### 一、下一问号节点概率
显示当前 ? 节点的实际房间概率，自动适配以下修正：

| 优先级 | 修正源 | 效果 |
|--------|--------|------|
| 1 | **灯火钥匙** (LanternKey) + 第三幕 | 事件 100% |
| 1 | **黄金罗盘** (GoldenCompass) 匹配章节 | 事件 100% |
| 2 | **黑名单** (父节点是商店 / 唯一子节点是商店) | 商店 0%，事件吸收 |
| 3 | **佛珠手链** (JuzuBracelet) | 小怪 0%，事件吸收 |

### 二、当前章节事件池
列出当前章节可能遇到的所有事件，按状态分色：
- **白色** = 可触发（条件满足）
- **灰色** = 条件不满足（如金币/药水不够）

特殊处理：
- **战史学家 付袭** (WarHistorianRepy)：持有灯火钥匙进入第三幕时置顶白色显示
- 已访问过的事件自动隐藏
- 纯章节限制事件（如 脑蛭(BrainLeech) 仅在 Act1/2 出现）在无关章节自动隐藏
- 标题显示格式 `事件池 20/28 (8未满足)`

### 三、药水掉落概率
显示当前动态药水掉落率，初始 40%，随战利品中是否包含药水浮动。  
精英战有额外12.5%的药水掉落率，本mod计算结果暂时不包含这一补正。

## 安装

1. 将 `map_info_mod` 文件夹放入游戏的 `mods` 目录：
   ```
   Slay the Spire 2/mods/map_info_mod/
   ├── MapInfoMod.json
   └── map_info_mod.dll
   ```
2. 启动游戏，主菜单 → 设置 → 模组设置 → 确保勾选「地图信息面板」
3. 开始对局，打开地图即可看到面板

## 兼容性

- **最低游戏版本**：0.107.0 （开发基于beta107进行，老版本没有测试过）
- **模组类型**：纯 DLL，无 PCK 资源包
- **不影响游戏性**：仅信息显示，不修改任何游戏逻辑
- **已知限制**：
  - 首次游戏教程 ? 节点固定出事件不特殊显示
  - 自定模式词条 致命事件(DeadlyEvents)（精英会出现在 ? 节点中）不特殊显示
  - 事件条件判断字典为硬编码，需手动更新
