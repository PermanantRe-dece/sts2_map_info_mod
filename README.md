# 地图信息面板 (Map Info Mod)

杀戮尖塔2 (Slay the Spire 2) v0.107.0 的 DLL 模组，在地图界面叠加信息面板。

## 功能

### 一、下一问号节点概率
显示当前 ? 节点的实际出房概率，自动适配以下修正：

| 优先级 | 修正源 | 效果 |
|--------|--------|------|
| 1 | **灯火钥匙** (LanternKey) + 第三幕 | 事件 100% |
| 1 | **黄金罗盘** (GoldenCompass) 匹配章节 | 事件 100% |
| 2 | **黑名单** (父节点是商店 / ? 唯一子节点是商店) | 商店 0%，事件吸收 |
| 3 | **佛珠手链** (JuzuBracelet) | 小怪 0%，事件吸收 |

概率分两行显示：
```
?节点: 事件85% 小怪10%
           宝箱2% 商店3%
```

### 二、当前章节事件池
列出当前章节可能遇到的所有事件，按状态分色：
- **白色** = 可触发（条件满足）
- **灰色** = 条件不满足（如金币/血量不够）

特殊处理：
- **战史学家雷皮** (WarHistorianRepy)：持有灯火钥匙进入第三幕时置顶白色显示
- 已访问过的事件自动隐藏
- 纯章节限制事件（如 BrainLeech 仅在 Act1/2）在无关章节隐藏
- 标题显示 `事件池 20/28 (8未满足)`

### 三、药水掉落概率
显示当前动态药水掉落率，初始 40%，随战斗结果浮动。

## 安装

1. 将 `map_info_mod` 文件夹放入游戏的 `mods` 目录：
   ```
   Slay the Spire 2/mods/map_info_mod/
   ├── MapInfoMod.json
   └── map_info_mod.dll
   ```
2. 启动游戏，主菜单 → 模组 → 启用「地图信息面板」
3. 开始对局，打开地图即可看到面板

## 调试模式

如遇到问题需要输出详细日志，修改 `MapInfoMod.dll` 同级目录下的配置，或将 `EventConditionDb.cs` 中的：
```csharp
public static bool VerboseLogging { get; set; } = false;
```
改为 `true` 后重新编译。日志会输出路线历史、遗物列表、概率计算细节。

## 兼容性

- **最低游戏版本**：0.107.0
- **模组类型**：纯 DLL（无 PCK 资源包）
- **不影响游戏性**：仅信息显示，不修改任何游戏逻辑
- **已知限制**：
  - 首次运行教程 ? 节点固定出房不特殊显示
  - 自定模式词条 DeadlyEvents（精英 ? 节点）不特殊显示
  - 事件条件判断字典需手动跟进游戏更新
